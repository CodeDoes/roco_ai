# Jules Tooling

The Jules tooling provides a command-line interface to manage Jules agents, batch operations, and API key management without exposing credentials.

## Available Commands

The following commands are available to interact with Jules agents and sessions:

*   **`check`**: Validates the Jules API key. Output masks the key for security.
*   **`spawn`**: Spawns a new agent or a batch of agents.
*   **`queue`**: Lists or manages the current queue of agents or tasks.
*   **`watch`**: Streams activities and logs from a running session in real-time.
*   **`supervise`**: Attaches a supervisor to an active session to monitor and control agent execution.
*   **`prs`**: Lists Pull Requests generated by Jules sessions.
*   **`send`**: Sends a message or prompt to the agent in a specified session.
*   **`approve`**: Approves a pending plan generated by an agent.

## API Key Resolution

The tooling ensures the API key is NEVER hardcoded, echoed, or committed.
The key is securely resolved by reading from `.env` in the repository root. The key is normalized at runtime by stripping surrounding single or double quotes and removing any newlines.

## Example: Running a Supervised Batch of 3-5 Agents

To run a supervised batch of agents, you can spawn them and attach the supervisor:

```bash
# 1. Spawn a batch of 5 agents for a specific task
scripts/jules.sh spawn --batch 5 "Evaluate the new caching layer"

# 2. Check the queue to ensure they are properly scheduled
scripts/jules.sh queue

# 3. Supervise the batch to monitor their progress and plans
scripts/jules.sh supervise --batch-id <BATCH_ID>

# 4. Once they generate plans, approve them if they look correct
scripts/jules.sh approve <SESSION_ID>
```
